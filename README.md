# CA Final Study Command Center

Mobile-first PWA for CA Final preparation.

**Study start:** 24 September 2026  
**Lecture target:** 15 December 2026  
**Syllabus target:** 31 December 2026  
**Exam horizon:** configurable; the website does not expire.

## Deployment

This project is configured for GitHub Pages using:

`.github/workflows/pages.yml`

See `GITHUB_SETUP.md` for phone-only deployment instructions.

## Main features

- FR / AFM / DT / GST / Audit tracking
- Smart scheduling
- Backlog recovery
- Spaced revision
- RTP / MTP / tests
- Daily and weekly planning
- PWA / Add to Home Screen
- IndexedDB persistence
- Rolling snapshots
- JSON backup and restore
- Google Drive private app-data backup
- Google Calendar availability + dedicated study-calendar sync

## Important

Keep the GitHub Pages URL stable. Your browser's local study data is tied to the website origin.
